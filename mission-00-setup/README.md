# Mission 0 — Repository setup

## Goal

Set up a public repository for the Digital Detective assignment and organize the work into mission folders.

## What I set up

The repository has a README for each mission, plus folders for the related files and evidence. Keeping the missions separate makes it easier to go back to a particular topic.

The repository was initially named `digital-detective-8531`; its current name is `digital-detective-8054`.

## Tools

- Python and Git version checks
- GitHub CLI (`gh`)
- `git init`, `git add`, `git commit`, and `git push`

## What I learned

A Git repository keeps project files together with their change history. GitHub hosts that repository online, where the files and their history can be viewed and shared.
