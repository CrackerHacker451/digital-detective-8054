# Digital Detective

This repository is my work for the Diwali independent learning assignment. The missions cover computer basics, using the terminal, operating systems, programs, number systems, Git and GitHub, and networking.

I kept the topics in separate folders so I can find each set of notes without digging through one long document. The final mission collects the report, and Mission 5 includes a small number converter you can run with Python 3.
