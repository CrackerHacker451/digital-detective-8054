# Mission 1 — Know your computer
## 1. Task / objective
Explain IPOS, classify hardware and software, and identify everyday computer-based systems.
## 2. Work completed
### Task 1.1 — IPOS: typing and saving a document
| Stage | What happens | Hardware/component |
|---|---|---|
| Input | I type text and press save. | Keyboard and storage interface |
| Processing | The application receives characters, formats them and prepares file data. | CPU and RAM |
| Output | The document appears on screen and the application confirms saving. | Screen and application window |
| Storage | The file is written to the computer's drive. | SSD/flash storage or cloud storage |

The activity moves from a keyboard action to a running application, then to visible feedback, and finally to persistent storage.

## 3. Commands / tools used
No Terminal commands were required. I used the computer's About/System Information and the applications I commonly use.
## 4. My understanding
IPOS describes a complete cycle: information enters, is processed, is shown or acted on, and may be saved. Hardware is the physical equipment, while software gives it instructions. Everyday systems follow the same pattern on a smaller or specialized scale.
